Coze 答题助手

识别 Coze 对话里的题目 → 调模型生成答案 → 填入输入框。默认发送前需要你点确认。

模型

读取 tools/env.local.json，该文件不入库

扩展默认没有网络权限，必须在这里点一次「授权访问接口地址」，请求由后台发出。

自动化

自动登录

只在检测到登录表单时生效。学号和姓名只保存在本机浏览器存储，不会上传。

手动绑定（可选）

如果自动识别不到，在 Coze 页面用面板上的「输入框 / 消息列表 / 发送按钮」点选绑定，会自动写回这里。

使用说明

  1. 填入接口地址与 API Key，点「授权访问接口地址」，再「测试连接」。
  2. 打开 Coze 对话页，右下角出现面板，点「开始」。
  3. 识别到题目后自动生成答案并填入输入框，确认无误后点「发送」。
  4. 对方问「是否继续，回复是」，面板出现「发送『是』」按钮；勾选自动回「是」则由脚本自动发送。
  5. 识别不到元素时，用面板的绑定按钮点选一次，或导出调试信息。
